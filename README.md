# AI-помощник для товарных карточек

Локальный прототип для контент-менеджера B2B-магазина. Он принимает название
прибора, производителя, характеристики и описание, а затем подготавливает
SEO-заголовок и описание, список характеристик, поисковые запросы и заметку
для менеджера. Если Gemini недоступен, приложение показывает резервный черновик
по введённым данным.

## Запуск в Windows

Нужен Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

Для генерации через Gemini укажите свой ключ в `.env`:

```text
GEMINI_API_KEY=ваш_ключ
```

У каждого, кто запускает проект, должен быть собственный ключ. Не отправляйте
его другим и не добавляйте `.env` в Git. `.env` уже указан в `.gitignore`;
`.env.example` — только шаблон без рабочего ключа. Без ключа приложение
запустится, но будет выдавать локальный черновик, а не текст от ИИ.

Запустите сервер:

```powershell
python -m uvicorn app:app --reload
```

Форма: <http://127.0.0.1:8000>. Документация API: <http://127.0.0.1:8000/docs>.

## Что формирует приложение

- SEO-заголовок длиной до 70 символов.
- SEO-описание длиной 800–1200 символов.
- Структурированные характеристики и 3–5 поисковых запросов.
- Краткий блок для менеджера и предупреждение о недостающих данных.

API: `POST /api/v1/generate`. Примеры входных данных и результата для двух
товаров находятся в [examples_output.json](./examples_output.json).

В [prompts.py](./prompts.py) заданы правила для Gemini: не придумывать
характеристики и отмечать отсутствующие сведения. Значения характеристик в
ответе сверяются с исходными данными. При ошибке или таймауте Gemini сервис
возвращает локальный черновик; его SEO-текст составляется по шаблону и не
является результатом генерации ИИ.

## Ограничения

Это прототип, а не готовая CMS. Сгенерированный текст и применимость прибора
нужно сверить с паспортом изготовителя перед публикацией. Локальный черновик
не заменяет генерацию ИИ и может требовать редакторской доработки.
