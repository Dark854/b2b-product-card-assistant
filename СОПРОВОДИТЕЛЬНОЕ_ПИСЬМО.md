# Сопроводительное сообщение

Здравствуйте! Я разработал локальный прототип помощника для подготовки карточек контрольно-измерительных приборов для B2B-магазина.

Сервис принимает данные о товаре через веб-форму или API и подготавливает SEO-заголовок и описание, характеристики, поисковые запросы и блок для менеджера. Я добавил проверку формата и длины результата, обработку некорректного ввода и промпт, запрещающий модели придумывать технические характеристики. API-ключ задаётся отдельно в локальном `.env`, который исключён из Git. Примеры для двух товаров включены в проект.

Во время проверки Google Gemini возвращал `503 UNAVAILABLE`, поэтому подтвердить успешную генерацию через API не удалось. Чтобы сервис не заканчивался ошибкой, я добавил ограничение ожидания и резервный локальный черновик из введённых данных с предупреждением. Этот черновик не выдаётся за результат ИИ. Также я оформил результат в виде карточки на веб-странице и добавил копирование.

Проверил валидацию примеров и входных данных, обработку ошибки API, резервный режим и отображение карточки. Перед публикацией результат нужно сверять с паспортом изготовителя.
